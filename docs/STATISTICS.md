# Statistical analysis

`fgpvdta summarize` uses the prediction CSVs of completed observed runs. It
verifies their checksums when present and recomputes MSE, concordance index,
Pearson and Spearman. CI is exact O(n log n), excludes equal target-label pairs,
and awards one half for prediction ties. Nonfinite predictions fail; undefined
correlations are null/NaN, never silently treated as zero.

Each experiment must have one shared split and identical training-seed sets for
all variants. The CLI expects 11/22/33/44/55 unless `--expected-seeds` overrides
that list. Summary tables report mean and sample SD (ddof=1); one seed has no
defined sample SD.

Two units of inference are reported separately:

1. **Training seed:** paired effects in test-set metrics across matched seeds.
   Two-sided paired t-test is implemented as a one-sample t-test on differences,
   with percentile bootstrap intervals from resampled paired differences.
2. **Protein target:** compute each target's MSE for each seed, average target
   MSE effects over matched seeds, then use one paired effect per target for the
   t-test and target-level bootstrap. Repeated seed-target rows are not treated
   as independent observations. Entity IDs, row IDs and labels must match before
   pairing; equal CSV lengths alone are insufficient.

Default bootstrap settings: 10,000 replicates, RNG seed 42, 95% percentile interval.
Positive effects always mean improvement (baseline-minus-candidate for MSE,
candidate-minus-baseline for CI/correlations). Holm correction is applied to all
finite p-values generated by one invocation. Document the comparison family if
using multiple independent invocations. Constant nonzero effects have a degenerate
t-statistic, represented as missing; the limiting p-value is zero. Zero effects
have p=1. Insufficient finite pairs are labeled and omitted from inference.

Target-level inference assumes independent target units. Homologous targets and
shared drugs can create dependence; these tests do not establish performance on
arbitrary novel protein families. Seed-level uncertainty is conditional on the
chosen split. Sensitivity results must not be used to select a model on the test
set and then reported as an unbiased evaluation.

The lower-level historical analysis utilities are available in `statistics.py`
and `tables.py`. The CLI uses `reviewer.py`, including target-level tests and
explicit multiple-comparison handling.
